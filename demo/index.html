Welcome to DT Tool Identifier

Hold a design & technology tool up to your webcam and the app will identify it, show what it's used for, and quiz your class on tool recognition. You'll need a model trained with Google Teachable Machine first.

Go to teachablemachine.withgoogle.com → create an Image Project → train with your classroom tools → Export → copy the shareable link.

No model yet? Try the sample model below to explore the interface first.

How this works:
Your model was trained using transfer learning — it builds on top of MobileNet, a neural network that has already learned to recognise millions of images. Only the final "classification layer" was retrained with your photos.

Each frame from your webcam is resized to 224 × 224 px and passed through the network. The bars below show how confident the model is for each class (they always add up to 100%). The top result updates the fact card on the right.

Quiz mode picks a random class and asks students to hold up that tool. They must hold it steady for half a second (85 %+ confidence) to score a point.
